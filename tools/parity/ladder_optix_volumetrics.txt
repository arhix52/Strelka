    25_subsurface       0.118 @ 32, 0.079 @ 128  ->  b = 0.040, 0.059 @ 512

The two rows that moved, and the two that moved by less than they look:

  * `07_alpha_clip` 1.017 -> 1.015 and `08_alpha_blend` 1.018 -> 1.016, both
    with `rel` improving by 0.001. That is `misDistance`: the multiple-importance
    weight at an area light now measures the light's solid angle from the vertex
    that scattered rather than from wherever a cutout or a medium boundary
    restarted the ray. Metal has carried the same field for the same reason.
    Measured against a stashed build, so the delta is attributed rather than
    assumed.
  * `12_lights_punctual` at 0.974 is the control for that change: delta lights
    cannot be reached by a BSDF ray, so the weight never applies, and the row is
    unmoved to three digits.

That furnace run needed one change the checked-in script does not make: the
scene's sidecar asks for a colour-only environment, and the OptiX backend renders
that black -- `MissData::bg_color` is pinned to zero and the environment is only
read when a texture path is present. The sky was written as a 16x8 constant EXR
instead, which is the same instrument in the form this backend reads. That gap is
a hand-off; it is not in the walk.
